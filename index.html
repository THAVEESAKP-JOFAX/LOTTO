07 · แจ้งเตือน

ส่ง Alert เข้ากลุ่ม LINE

อัตโนมัติ: เช้าวันออกรางวัล 09:00 น. ส่งเลขของ 🧠 AI ปรับตัว และหลังผลออก (15:30–18:30 น.) ส่งผลรางวัลพร้อมตรวจเลขของ bot · พิมพ์ “เลขเด็ด” หรือ “ผลหวย” ในกลุ่มได้ตลอด

ส่งด้วยตัวเอง

ตั้งค่าครั้งแรก

  1. สร้าง LINE Official Account และเปิด Messaging API ที่ LINE Developers
  2. ตั้ง Webhook URL เป็น /api/line/webhook แล้วเปิด “Allow bot to join group chats”
  3. ใส่ค่าใน Netlify → Environment variables: LINE_CHANNEL_ACCESS_TOKEN, LINE_CHANNEL_SECRET, ALERT_ADMIN_KEY
  4. เชิญ bot เข้ากลุ่ม — bot จะตอบ Group ID กลับมา นำไปใส่ใน LINE_GROUP_IDS (หลายกลุ่มคั่นด้วย ,)

LINE Notify ปิดบริการแล้ว จึงใช้ Messaging API · แพ็กเกจฟรีมีโควตาข้อความต่อเดือน และการส่งเข้ากลุ่มนับตามจำนวนสมาชิกในกลุ่ม

08 · ผลย้อนหลัง

ผลรางวัลทุกงวด

อ่านก่อนเล่น

การออกรางวัลสลากเป็นการสุ่ม ทุกเลขมีโอกาสเท่ากันทุกงวด สถิติในอดีตไม่ได้เพิ่มโอกาสถูกในงวดถัดไป เงินรางวัลรวมทั้งหมดเท่ากับประมาณ 60% ของยอดขาย แปลว่าระยะยาวผู้เล่นเสียเฉลี่ย 40%

เว็บนี้ทำเพื่อการศึกษาและความบันเทิง ไม่ใช่คำแนะนำการลงทุน · ผู้ซื้อสลากต้องมีอายุ 20 ปีขึ้นไป · ซื้อสลากในราคาไม่เกิน 80 บาท · ไม่สนับสนุนหวยใต้ดิน
